# Software Requirements Specification (SRS)

## Overview
RetailPOS is a modern Point of Sale system designed for retail stores. It supports product management, barcode-driven checkout, inventory tracking, billing, reporting, and role-based user access.

## Functional Requirements
- User authentication and role management
- Product and category management
- Inventory updates and stock alerts
- Barcode-based sales workflow
- Billing and receipt generation
- Customer and supplier management
- Sales and inventory reports

## Non-Functional Requirements
- Responsive UI
- Secure authentication
- Reliable data persistence
- Scalable architecture
