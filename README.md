# RetailPOS

A modern Point of Sale (POS) system built for retailers.

## Features
- Product Management
- Inventory Management
- Barcode Scanner Support
- Sales & Billing
- Thermal Receipt Printing
- Customer Management
- Supplier Management
- Sales Reports
- User Roles
- Dashboard

## Tech Stack
- Frontend: React / Next.js
- Backend: NestJS
- Database: MySQL
- ORM: Prisma
- Authentication: JWT
- Receipt Printing: Thermal Printer
