# RetailPOS

RetailPOS is an offline-first, portable Point of Sale (POS) and inventory control system.

## Quick Start Directory

1. **`install.bat`** : First-time setup utility to install dependencies, run migrations, and build files.
2. **`run.bat`** : One-click script to boot both NestJS and Next.js services and open the browser.
3. **`stop.bat`** : Gracefully stops and shuts down server processes, freeing network ports.
4. **`backup.bat`** : Backs up the MySQL database schemas to the `backups/` folder.
5. **`restore.bat`** : Restores any saved SQL backup file into MySQL.

---
