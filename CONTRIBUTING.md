# Contributing

Thank you for contributing to RetailPOS.

## Ways to Contribute

- Report bugs and suggest improvements
- Submit pull requests for features or fixes
- Improve documentation and testing coverage

## Development Guidelines

- Keep changes focused and well documented
- Follow the existing project structure
- Write or update tests when changing behavior
- Use clear commit messages

## Pull Request Process

1. Create a feature branch from the latest main branch.
2. Make your changes and verify them locally.
3. Open a pull request with a concise summary and testing notes.
