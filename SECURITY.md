# Security Policy

## Supported Versions

The current development branch is the primary target for security fixes.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by emailing the maintainer or opening a confidential issue through GitHub.

## Expectations

- Do not publicly disclose vulnerabilities before a fix is available.
- Provide as much detail as possible, including reproduction steps and impact.
- Avoid testing against live production systems unless explicit permission is granted.
